# Room 115 — AI Basics Passport

Standalone, self-paced AI-literacy website for AI Study Studio at Nantucket High School.

## Deployment

This is a **static website**. No package installation, API keys, or build commands are required.

1. Put `index.html` and the entire `videos/` folder at the **root** of a fresh GitHub repository.
2. Open [Vercel New Project](https://vercel.com/new), import that repository from GitHub.
3. Set **Framework Preset** to **Other**, **Root Directory** to `./`, and leave the **Build Command** empty. Click **Deploy**.
4. Test the course homepage, interactive practice, and both video players on a student Chromebook.
5. Use the Vercel production URL in Google Classroom. Future pushes to the repository automatically update the deployment.

## Included

- `index.html`: standalone interactive app, no dependencies.
- `videos/ai-01-intro-to-ai.mp4`: teacher-supplied 1:30 intro video.
- `videos/ai-02-machine-learning.mp4`: teacher-supplied 2:53 supplemental video.

No student login. Progress is stored on the browser/device only. It does **not** submit classwork to the teacher.

The **official 25-question AI Basics certification test, student study-artifact submissions, and badge approval** remain in the existing teacher workflow and are not managed by this website.
